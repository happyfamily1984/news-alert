## 이번 버전에서 바뀐 것 (개발 기록)

- 첫 실행 빈 화면 방지
  - 키워드가 한 번도 저장된 적 없으면 추천 키워드(경제·부동산·AI) 등록.
    사용자가 모두 지우면 다시 넣지 않음.
  - 키워드와 상관없는 최신 뉴스를 매 확인마다 저장 (언론사별 최대 10건, 최대 60건).
  - 홈: 키워드 아래 '최신 뉴스' 5건(언론사를 섞어서) + 더보기.
  - 매칭 뉴스 탭: '키워드 뉴스 / 최신 뉴스' 전환. 키워드 뉴스가 없으면 최신 뉴스부터.
  - 앱을 열거나 앱으로 돌아올 때 마지막 확인이 10분 넘었으면 바로 확인.
  - 불러오는 중 / 실패(다시 시도) / 없음(지금 확인) 상태를 구분해 표시.
    모든 피드가 실패하면 저장된 기사를 지우지 않고 이전 기사 + 안내 띠를 보여줌.
  - 발행 30일이 지난 기사는 저장하지 않음.
- 발행일 버그 수정: 연합뉴스(+0900)·조선일보(+0000) 형식을 읽지 못해 '가져온 시각'으로
  표시하던 문제. 이미 저장된 기사도 다음 확인 때 올바른 발행일로 고쳐짐.
- 카드 맨 위에 언론사·발행 일시, 상세에 '출처 / 발행' 줄과 저작권 안내.
- 설정 > 문의 (이메일·웹사이트), 메일 앱이 없으면 주소 복사.
- 키워드 태그가 줄 전체 폭으로 늘어나 보이던 문제 수정.
