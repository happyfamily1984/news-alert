# 뉴스 알리미 디자인 시안 v3 (2026-11-15, 사용자 제공 스크린샷 5장)

사용자가 새 시안 스크린샷 4장(홈/설정/키워드 추가/매칭 뉴스) + 새 앱 아이콘 1장을 보내
"이거로 다시 적용해"라고 지시. v2의 수치 조정과 달리 전체 비주얼 리디자인이라
레이아웃·색상·일러스트까지 새로 적용했다.

## 전체
- 배경: 라이트 그라데이션 #F5F8FF → #E9F0FD + 옅은 파란 장식 원 2개
  (다크 모드는 단색 #121923 유지). AppBackground 위젯이 담당.
- 카드: 흰색, 모서리 20dp, 옅은 그림자(검정 6%·blur 16·y 6). 테두리 없음.
- 버튼: 파란 그라데이션 #5EA0F8 → #1F63EC, 모서리 18dp, 높이 60dp,
  파란 그림자. GradientButton 위젯.
- 외곽선 버튼: 흰 배경 + 파란 테두리 1.5dp + 파란 글자 ('지금 확인').
- Primary #246BCE 유지. 글자 #172B4D, 보조 #667085.
- 폰트: Noto Sans KR (Pretendard는 Google Fonts에 없음).

## 홈
- 헤더: 파란 그라데이션 둥근 박스 + 흰 종 아이콘 + '뉴스 알리미' 24 Bold.
  오른쪽 종 아이콘에 오늘 매칭 뉴스가 있으면 빨간 점.
- 요약 카드: 대각선 그라데이션 #7198FF → #2462E9, 모서리 20dp,
  '오늘의 매칭 뉴스' 17 Medium, 건수 44 Bold, 칩 '✓ 키워드 N개 모니터링 중'
  (흰색 18% pill), 오른쪽 신문 아이콘, 우상단 반투명 원 속 '>' (탭하면 뉴스 목록).
- '방금 확인' 행: 시계 아이콘 + '방금 확인' 15 SemiBold + 오른쪽 '전체보기 >' pill.
- 빈 상태: 돋보기 일러스트(assets/illustrations/empty_search.png),
  '아직 등록된 키워드가 없습니다' 19 Bold,
  '관심 있는 키워드를 등록하면 관련 뉴스를 알림으로 받아볼 수 있어요!' 15,
  '+ 키워드 추가하기' 그라데이션 버튼, 아래 '지금 확인' 외곽선 버튼.
- 키워드가 있어도 '지금 확인' 외곽선 버튼은 항상 표시.

## 설정
- 헤더: 파란 톱니 아이콘 + '설정'.
- 섹션 제목: 파란 세로 막대(4x18) + 17 Bold ('알림 설정', '앱 설정').
- 행: 앞 원형 아이콘 칩 48dp (배경 #EBF1FD, 파란 아이콘 22),
  이름 16 Medium + 설명 13, 구분선은 칩 뒤부터 (왼쪽 여백 80).
- 아이콘: 전체 알림=종, 확인 주기=RSS, 새 뉴스만=종(빗금),
  알림 테스트=영수증, 테마=팔레트, RSS 출처=RSS, 앱 버전=정보.
- 토글 파란색, 드롭다운은 값 + 아래 화살표.

## 키워드 추가
- 히어로 일러스트(assets/illustrations/hero_add_keyword.png, 스크린샷에서 크롭).
- 제목 '관심 있는 뉴스 키워드를 등록해 보세요.' 22 Bold 가운데 정렬.
- 설명 '원하는 키워드를 입력하면 관련 뉴스만 빠르게 확인할 수 있어요!' 15 가운데 정렬.
- 입력창: 모서리 20dp, 돋보기 아이콘, placeholder '예) 인공지능, 부동산, 전기차'.
- '등록하기' 그라데이션 버튼 + 오른쪽 '>'.
- 하단: 파란 정보 아이콘 + '연합뉴스 RSS에서 해당 키워드가 포함된 뉴스를 확인합니다.'

## 매칭 뉴스
- 헤더: 파란 종 아이콘 + '매칭 뉴스' + 오른쪽 새로고침.
- 빈 상태: 신문+돋보기 일러스트(assets/illustrations/empty_news.png),
  '아직 매칭된 뉴스가 없습니다.' 19 Bold,
  "키워드를 등록하고 '지금 확인'을 눌러보세요." ('지금 확인'만 파란 Bold).
- 팁 카드: 배경 #EAF2FF, 모서리 16dp, 파란 원 속 전구 아이콘 +
  '키워드를 등록하면 관심 있는 뉴스를 더 빠르게 받아볼 수 있어요!'.

## 앱 아이콘 (v3, 초록)
- 사용자가 보낸 초록/민트 그라데이션 아이콘(흰 신문 + 초록 종, 1254x1254).
  원본: docs/app-icon-source-v3.png.
- mipmap 5종(48/72/96/144/192) + 원형 버전, drawable foreground(1024, 원본 66%),
  adaptive 배경색 #35C39D (타일 초록에서 샘플링).
- 참고: 이전 파란 아이콘(v2) 파일들은 같은 경로에 덮어써서 교체됨.

## 하단 내비게이션
- 가운데 탭 라벨을 '뉴스'에서 '매칭 뉴스'로 변경 (시안과 화면 제목에 맞춤).
  시안에서 홈 화면 탭은 '알림 내역'으로 돼 있으나, 매칭 뉴스 화면 탭은
  '매칭 뉴스'라 일관되게 '매칭 뉴스'로 통일했다.
