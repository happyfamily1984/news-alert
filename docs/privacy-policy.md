# 뉴스 알리미 개인정보처리방침

시행일: 2026년 11월 26일

'뉴스 알리미'(이하 '앱')는 사용자의 개인정보를 수집하지 않습니다. 이 문서는 앱이 어떤 정보를 어디에 저장하고, 어떤 외부 서버와 통신하는지 설명합니다.

## 1. 수집하는 개인정보

앱은 이름, 이메일, 전화번호, 위치, 기기 식별자 등 어떤 개인정보도 수집하지 않습니다. 회원가입이나 로그인 기능이 없습니다.

## 2. 기기 안에만 저장하는 정보

다음 정보는 사용자의 휴대폰 안에만 저장되며, 개발자나 제3자에게 전송되지 않습니다.

- 사용자가 등록한 키워드 (처음 설치하면 추천 키워드 '경제', '부동산', 'AI'가 들어가 있으며 지울 수 있음)
- 키워드와 일치한 기사 목록과 최신 기사 목록(제목, 요약, 링크, 언론사, 발행 시각, 최근 30일분)과 읽음 표시
- 앱 설정(알림 사용 여부, 확인 주기, 테마, 뉴스 출처 선택)
- 자동 확인이 마지막으로 실행된 시각과 결과

앱을 삭제하면 위 정보도 모두 삭제됩니다.

## 3. 외부 서버와의 통신

앱은 새 기사를 확인하기 위해 아래 언론사·서비스의 공개 RSS 주소에 접속합니다. 이때 일반적인 인터넷 접속과 마찬가지로 해당 서버가 사용자의 IP 주소 등 접속 기록을 남길 수 있으며, 이는 각 서비스의 개인정보처리방침을 따릅니다. 앱은 이 요청에 키워드나 개인정보를 담아 보내지 않습니다.

- 연합뉴스 (yna.co.kr)
- 조선일보 (chosun.com)
- 동아일보 (donga.com)
- 구글 뉴스 (news.google.com): 중앙일보·YTN·MBC·KBS 기사 확인용

'원문 보기'나 알림을 누르면 기사 원문이 휴대폰의 웹브라우저로 열립니다.

## 4. 광고·분석 도구

앱에는 광고, 사용 통계 분석, 오류 수집 등 제3자 도구가 들어 있지 않습니다.

## 5. 권한

- 알림: 키워드 기사 알림을 보여주기 위해 사용합니다.
- 인터넷: 뉴스 RSS를 받기 위해 사용합니다.
- 기기 부팅 후 실행: 휴대폰을 다시 켠 뒤에도 자동 확인이 이어지게 하기 위해 사용합니다.
