# 뉴스 알리미

키워드를 등록하면, 해당 키워드가 포함된 뉴스(연합뉴스·조선일보·중앙일보·동아일보·YTN·MBC·KBS)가 올라올 때 알림을 주는 안드로이드 앱입니다.

## 기능 (v1)

- **키워드 관리**: 키워드 추가/삭제, 목록 표시 (폰에 저장)
- **RSS 수집**: 언론사 RSS를 주기적으로 확인해 제목·요약에서 키워드 포함 여부를 검사 (대소문자 무시, 여러 키워드는 OR, 영문 키워드는 단어 단위로 비교)
- **매칭 뉴스 목록**: guid 기준 중복 제거, 최대 100건 유지, 매칭된 키워드와 수집 시간 함께 저장. 같은 기사가 여러 키워드에 매칭되면 한 번만 보여주고 키워드를 함께 표시
- **알림**: 새 매칭 기사가 있으면 로컬 알림 (한 번의 확인에서 최대 5건)
- **백그라운드 확인**: WorkManager로 15분 간격 주기 작업 (안드로이드 최소 간격). 앱 안의 '지금 확인' 버튼으로 수동 확인도 가능
- **화면**: 홈(키워드 목록 + 오늘 매칭 건수) / 키워드 추가 / 매칭 뉴스 목록(키워드 하이라이트) / 기사 상세(RSS 요약 + 원문 보기) / 설정(알림 on/off, 확인 주기 15/30/60분, 테마)
- **테마**: 라이트/다크 모드 지원 (시스템 설정 따름, 설정에서 변경 가능)

## 사용법

1. APK를 설치하고 앱을 연다.
2. 홈 화면 오른쪽 아래 `+` 버튼으로 키워드를 등록한다. (예: 인공지능, 부동산, 전기차)
3. 등록한 키워드가 포함된 기사가 올라오면 알림이 온다.
4. 뉴스 탭에서 매칭된 기사를 보고, 기사를 누르면 요약과 원문 보기 버튼을 볼 수 있다.
5. 설정에서 알림 on/off, 확인 주기(15/30/60분), 테마를 바꿀 수 있다.

## 뉴스 출처

- **연합뉴스 RSS (메인)**: API 키 없이 사용한다.
  - 전체: https://www.yna.co.kr/rss/news.xml
  - 카테고리: 정치·경제·사회·국제·문화·스포츠·산업·연예·지역 (같은 패턴의 RSS 주소)
- **조선일보 RSS**: 전체 피드 하나 (`chosun.com/arc/outboundfeeds/rss/`)
- **동아일보 RSS**: 전체 + 정치·경제·사회·국제 (`rss.donga.com`). 응답에 문자셋 표시가 없어 UTF-8로 직접 디코딩한다.
- **중앙일보·YTN·MBC·KBS (구글 뉴스 RSS)**: 직접 피드가 막혀 있어 `site:` 검색 + `when:1d`(최근 하루)로 가져온다. 요약이 없어 제목으로만 매칭되고, 원문 링크는 구글 뉴스를 거쳐 열린다. 설정에서 출처별로 켜고 끌 수 있다.
- RSS에는 기사 전문이 없어 상세 화면에서는 요약까지만 보여주고, 전문은 '원문 보기' 버튼으로 외부 브라우저에서 연다.

## 디자인

- 컨셉: Modern News Monitor (ChatGPT 시안, `docs/design-draft.md` 참고)
- Flutter Material 3 기반, 라이트/다크 모드 지원
- 모든 색상·폰트·크기는 `lib/theme.dart` 한 곳에 모아둔다. 위젯에서 색상 hex를 직접 쓰지 않는다.
- 폰트: 시안은 Pretendard를 지정했지만, Pretendard는 Google Fonts에 없어 `google_fonts` 패키지로 불러올 수 없다. v1에서는 Google Fonts의 Noto Sans KR을 적용했다. Pretendard TTF 파일을 로컬에 등록하면 `lib/theme.dart`의 폰트 호출만 바꾸면 된다.

## 빌드

main 브랜치에 푸시하면 GitHub Actions(`.github/workflows/build-apk.yml`)가 자동으로 release APK를 빌드해 artifact로 올린다.

- Flutter 3.32.0 (stable), Java 17, Gradle 8.9
- APK: Actions 탭 → 해당 실행 → Artifacts → `news-alarm-release-apk`에서 `app-release.apk` 다운로드
- APK는 저장소에 들어 있는 고정 키스토어(`android/app/app-keystore.p12`)로 서명한다. 키와 비밀번호가 공개돼 있으므로 직접 설치용으로만 쓰고, Play 스토어 출시 시에는 별도 비공개 키스토어로 교체해야 한다.

## 플레이스토어 출시

- 출시 절차·플레이 콘솔 입력값: `docs/play-store/release-guide.md`
- 등록정보 문구: `docs/play-store/listing.md`, 이미지: `docs/play-store/graphics/`
- 개인정보처리방침: `docs/privacy-policy.md`
- 플레이용 AAB는 비공개 업로드 키로 서명한다 (깃허브 시크릿 `UPLOAD_*`). 업로드 키는 저장소에 없다.

## 향후 과제

- **서버 + FCM 푸시**: 시안에서 서버 연동을 추천했지만, v1은 폰 안에서만 도는 로컬 앱이 목표라 로컬 WorkManager + 로컬 알림 방식을 쓴다. 서버를 두면 실시간 푸시와 키워드별 서버 측 필터링이 가능해진다.
- **기사 전문**: RSS 요약이 아닌 본문을 가져오려면 기사 페이지 파싱이 필요하다.
- **Pretendard 폰트**: TTF 파일을 `assets/fonts/`에 넣고 `pubspec.yaml`에 등록하면 시안대로 바꿀 수 있다.
